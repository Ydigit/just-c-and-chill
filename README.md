# Just C and Chill

This repository is a collection of most of the exercises and examples provided by the professor of the Data Structures course taught at the University of Beira Interior (UBI). The main goal of this project is to support the academic community by providing access to the codes developed during the classes.

## Contents:
- **ABPBALANCEADA**: Implementation of Balanced Binary Trees.
- **ARVORESBIN**: Examples and exercises on Binary Trees.
- **FILAS**: Code related to Queue structures.
- **ListasLigadas**: Implementations and exercises on Linked Lists.
- **PILHASEFILAS**: Sets of exercises involving Stacks and Queues.
- **SEARCHBT**: Search algorithms in Binary Search Trees (BST).
- **fichaaed1**: Collection of exercises from the course.

All the code in this repository is the intellectual property of the students and aims to serve as a learning resource. None of the code is protected by copyright from the instructor(s). If you have any questions or need further information, please contact the repository owner.
